# How to Create Sample Test Documents

To test DocuMind's multimodal capabilities, you need documents that contain text, tables, and charts.

Please create 2-3 test PDFs using Google Docs, Microsoft Word, or LibreOffice:

1. **quarterly_report.pdf**
   - Create a fake company quarterly report.
   - Write 2-4 pages of text (executive summary, business review).
   - Insert 2 tables (e.g., quarterly financials, product metrics).
   - Insert 1 bar chart (e.g., revenue by quarter). Insert this as an image into the document.
   - Insert 1 line graph (e.g., user growth trend).
   - Export/Save as PDF.

2. **technical_spec.pdf**
   - Create a fake technical document.
   - Write dense technical text with headings and subheadings.
   - Draw 1 architecture diagram (e.g., using Google Drawings or draw.io) and insert it as an image.
   - Insert 1 comparison table (e.g., feature matrix).
   - Format one of the pages with multiple columns to test layout handling.
   - Export/Save as PDF.

3. **scanned_doc.pdf**
   - Print one of the above documents on paper.
   - Scan it back using a scanner or a phone scanner app (like Adobe Scan).
   - Save it as a PDF.
   - This will test the OCR fallback for scanned/degraded pages.
